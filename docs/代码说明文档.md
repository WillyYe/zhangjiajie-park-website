# 张家界国家森林公园网站 - 代码说明文档

## 项目概述

本项目是为张家界国家森林公园开发的中英文双语官方网站，参考慕田峪长城官网设计风格，采用现代化前端技术实现。

- **项目名称**: 张家界国家森林公园官方网站
- **技术栈**: 原生 HTML5 + CSS3 + JavaScript (无框架依赖)
- **语言支持**: 中文/英文双语 (i18n)
- **代码规模**: 1612 行 (含 CSS/HTML/JS)
- **文件大小**: 约 52KB


**设计理念**: 集中管理应用状态，便于状态追踪和调试。

### 2. 国际化 (i18n) 实现

#### 数据结构

```javascript
var i18n = {
  en: {
    nav_news: 'Park News',
    nav_scenic: 'Core Scenic',
    // ... 更多键值对
  },
  zh: {
    nav_news: '公园资讯',
    nav_scenic: '核心景观',
    // ... 更多键值对
  }
};
```

#### 工作原理

1. HTML 元素添加 `data-i18n="key"` 属性
2. `switchLang(lang)` 函数遍历所有带属性的元素
3. 根据当前语言从 `i18n` 对象中查找对应文本并替换

#### 核心函数

```javascript
function switchLang(lang) {
  AppState.currentLang = lang;
  
  // 更新语言切换按钮状态
  document.querySelectorAll('.lang-switch button').forEach(...);
  
  // 更新所有 i18n 元素
  document.querySelectorAll('[data-i18n]').forEach(function(el) {
    var key = el.getAttribute('data-i18n');
    if (i18n[lang] && i18n[lang][key]) {
      el.textContent = i18n[lang][key];
    }
  });
  
  // 重新渲染动态内容
  renderNews();
  renderExperience();
  renderGallery();
}
```

### 4. 轮播功能 (`startHeroSlider`)

**功能特性**:
- 自动轮播 (每 5 秒切换)
- 手动点击切换
- 底部圆点指示器
- 切换时重置定时器

**实现逻辑**:

```javascript
function startHeroSlider() {
  var slides = document.querySelectorAll('.hero-slide');
  var dots = document.querySelectorAll('.hero-dot');
  
  // 清除已有定时器
  if (AppState.heroSlider) {
    clearInterval(AppState.heroSlider);
  }
  
  // 设置自动轮播
  AppState.heroSlider = setInterval(function() {
    slides[AppState.currentSlide].classList.remove('active');
    dots[AppState.currentSlide].classList.remove('active');
    
    AppState.currentSlide = (AppState.currentSlide + 1) % slides.length;
    
    slides[AppState.currentSlide].classList.add('active');
    dots[AppState.currentSlide].classList.add('active');
  }, 5000);
  
  // 绑定手动点击
  dots.forEach(function(dot, index) {
    dot.addEventListener('click', function() {
      // 切换到点击的幻灯片
      // 重置定时器
    });
  });
}
```

### 6. 画廊筛选 (`filterGallery`)

**功能**: 按类别筛选画廊图片

**类别**:
- `all` - 全部
- `scenic` - 风景
- `culture` - 人文
- `season` - 四季

**实现逻辑**:

```javascript
function filterGallery(cat, btn) {
  // 更新按钮状态
  document.querySelectorAll('.gallery-filter button').forEach(...);
  btn.classList.add('active');
  
  // 显示/隐藏图片
  document.querySelectorAll('.gallery-item').forEach(function(item) {
    if (cat === 'all' || item.dataset.category === cat) {
      item.style.display = '';
    } else {
      item.style.display = 'none';
    }
  });
}
```

### 7. 滚动动画 (`initFadeAnimation`)

**技术**: IntersectionObserver API

**功能**: 当元素进入视口时添加 `visible` 类，触发淡入动画

```javascript
function initFadeAnimation() {
  var fadeEls = document.querySelectorAll('.fade-up');
  
  if ('IntersectionObserver' in window) {
    var observer = new IntersectionObserver(function(entries) {
      entries.forEach(function(entry) {
        if (entry.isIntersecting) {
          entry.target.classList.add('visible');
        }
      });
    }, { threshold: 0.1 });
    
    fadeEls.forEach(function(el) {
      observer.observe(el);
    });
  } else {
    // 降级处理：直接显示
    fadeEls.forEach(function(el) {
      el.classList.add('visible');
    });
  }
}
```

**CSS 动画**:

```css
.fade-up {
  opacity: 0;
  transform: translateY(30px);
  transition: opacity 0.6s ease, transform 0.6s ease;
}
.fade-up.visible {
  opacity: 1;
  transform: translateY(0);
}
```

### 8. 头部滚动效果 (`handleHeaderScroll`)

**功能**: 页面滚动时改变导航栏样式

```javascript
function handleHeaderScroll() {
  var header = document.getElementById('header');
  if (window.scrollY > 100) {
    header.classList.add('scrolled');
  } else {
    header.classList.remove('scrolled');
  }
}
```

**CSS 效果**:

```css
.header {
  background: var(--green-dark);
  transition: background 0.3s, box-shadow 0.3s;
}
.header.scrolled {
  background: rgba(13, 43, 30, 0.98);
  box-shadow: 0 2px 20px rgba(0,0,0,0.2);
}
```

## 性能优化

### 1. 字体加载优化

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
```

使用 `preconnect` 提前建立与 Google Fonts 服务器的连接。

### 2. 滚动动画优化

使用 `IntersectionObserver` 替代 `scroll` 事件监听，避免性能问题。

### 3. CSS 动画优化

使用 `transform` 和 `opacity` 触发 GPU 加速，避免重排重绘。
